OS Support

BinaryBuilder produces binaries for Linux, macOS, Windows and FreeBSD with a single script.

CPU support

BinaryBuilder supports x86_64, i686, ARMv6, ARMv7, AArch64, PPC64LE and RISC-V. Automatically!

Language support

Build native binaries for your C, C++, Fortran, Rust, Go and OCaml packages.

Just tarballs

BinaryBuilder output is just a tarball. Grab the one for your ABI and go. No root or special tools required!

Hints

Common build systems are automatically detected. The wizard will give you the right command.

Cross-platform consistency

You can build for several platforms using the same toolchain, getting consistent binaries across all target systems.

Yggdrasil

Yggdrasil is the community build tree for BinaryBuilder recipes, where the binary packages of the Julia ecosystem are built.

Community-driven

Build recipes for thousands of packages are already available, contributed by the community.

JLL packages

Every merged recipe is built, uploaded and registered as a JLL package, so Julia users get the binaries with using LibFoo_jll.

Contributing

Add or update a package by opening a pull request with its recipe. CI builds it for every platform it targets.

GPUs

Build code for NVIDIA, AMD, Intel and Apple GPUs. For CUDA, Julia automatically installs the build that matches the user's CUDA version.

Parallelism

Build MPI and OpenMP code for parallel computing. Users can switch between MPI implementations, such as MPICH and Open MPI, without rebuilding.

Agents

Agents simplify authoring, guided by Yggdrasil's agent guide.
