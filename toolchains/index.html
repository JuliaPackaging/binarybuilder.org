BinaryBuilder

Toolchains

BinaryBuilder provides 50 compiler versions for 18 platforms. All of them run in the same sandboxed Linux environment, so one build recipe produces binaries for every platform.

A recipe chooses its compilers with the compilers keyword of build_tarballs and their versions with preferred_gcc_version, preferred_llvm_version, preferred_rust_version, preferred_go_version and preferred_ocaml_version. By default you get the oldest GCC that supports the platform, because older GCC versions produce binaries that run on more systems, and the newest LLVM, Rust, Go and OCaml. See Building Packages and the build tips for each language.
