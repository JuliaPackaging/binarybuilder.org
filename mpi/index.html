BinaryBuilder

MPI

Yggdrasil, the community build tree for BinaryBuilder recipes, builds packages that use MPI once for each of the 5 MPI implementations below, and tags each build with its implementation. Users choose an implementation with MPIPreferences.jl; without a preference, Julia uses MPICH, or Microsoft MPI on Windows. Julia then installs the matching build of every package, so switching implementations doesn't require rebuilding anything.

Use MPI from Julia with MPI.jl, and start a recipe from the HelloWorldMPI example.
