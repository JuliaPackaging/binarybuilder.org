BinaryBuilder

GPUs

Yggdrasil, the community build tree for BinaryBuilder recipes, builds packages for NVIDIA, AMD, Intel and Apple GPUs, and for the cross-vendor OpenCL, Vulkan and SPIR-V standards. Library versions on this page are the latest ones in Julia's General registry when the site was built.

NVIDIA

Yggdrasil recipes that use CUDA are built for 20 of the 21 CUDA toolkits below by default. Each build is tagged with its CUDA version, and Julia installs the one that works with the user's CUDA runtime: a build for CUDA 12.2 works with any CUDA 12 runtime from 12.2 onwards. Program NVIDIA GPUs from Julia with CUDA.jl, and start a recipe from the HelloWorldCUDA example.
